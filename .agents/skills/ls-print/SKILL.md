# Print / Outdoor Production

Не путай привлекательный превью и пригодный производственный файл. Сначала зафиксируй изделие, окончательные габариты в мм, масштаб, дистанцию чтения, освещённость, способ изготовления и ограничения подрядчика.

Для фасадного баннера: метраж, размер исходного растра в пикселях, эффективная плотность пикселей на ФИНАЛЬНОМ размере (с учётом масштаба проекта), расстояние зрителя, реальные детали изображения. Не требуй механически 300 ppi на 7-метровом фасаде; запроси допустимую плотность у типографии. При использовании upscale не выдавай придуманные текстуры человека/кожи за реальную детализацию.

Для маленькой таблички — SVG/PDF с реальным вектором, монтажными полями, расположением отверстий и безопасными отступами, если они известны. Отдельно указать материал (например, композит/ПВХ/акрил), толщину, плёнку/УФ-печать/гравировку и обработку краёв — как предложенный вариант, пока не подтверждён подрядчик.

Проверь: единицы измерения, bleed/crop marks только по требованиям поставщика, цветовой профиль CMYK/ICC по профилю производства или сохранение sRGB если оговорено, масштаб 1:1/1:10, чёткие контуры реза, отсутствующие/подменённые шрифты, QR на реальном физическом носителе, русский текст, исходник логотипа без перекраски. Конвертация в кривые допускается в копии печатной версии, оригинал должен остаться редактируемым.
