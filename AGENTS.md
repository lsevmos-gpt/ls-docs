# Линия спорта — правила агентной разработки дизайна

Этот репозиторий содержит сайт документации и систему Liniya Sporta Design Studio. Не изменять сайт, публикацию и GitHub Actions без отдельного задания. Ни один дизайн-файл не означает автоматическую публикацию.

## Когда применять
При задачах о дизайне «Линии спорта»: таблички, пиктограммы, типографика, интерьеры, вывески, навигация, оформление зон клуба, баннеры, печатная реклама, цифровые экраны, фирменные материалы. Для задач вне дизайна эти инструкции не заменяют профильные инструкции проекта.

1. Начать с навыка ls-design-studio: определить объект, носитель, статус исходников, подлинность и режим бренда.
2. Подключить 1–3 профильных навыка: ls-typography, ls-interior, ls-signage, ls-pictograms, ls-print, ls-brand, ls-digital-display.
3. Обязательно провести независимую проверку ls-design-critic перед статусом READY.
4. Для сложных концепций можно делегировать работу профильным субагентам из .codex/agents и дождаться их результатов. Делегирование не заменяет проверку готового макета.

## Приоритет источников
Прямая последняя инструкция заказчика по конкретному объекту > текущий указатель бренда Google Drive «00_CURRENT_VISUAL_GUIDE.txt» и указанные им действующие файлы MASTER/AI/QA > этот набор правил > архивы и общие референсы. На 23.10.2026 текущий указатель называет Visual System v1.7 от 18.10.2026. Проверять актуальность на каждом новом проекте. Не использовать файлы «ARCHIVE_DO_NOT_USE».

## Бренд
- Общеклубные материалы: Deep Forest #0A1E1E, Graphite #333F3F, Sport Green #1F822E, Electric Green #30B852; палитру применять осмысленно, без заливки всего макета зелёным.
- Направление всех групповых фитнес-занятий: самостоятельная тёплая палитра (Milk #F3EAE2, Cream #EFE2D6, Sand #D9C7B8, Dusty Rose #A96663, Graphite #1F1C1B), без зелёных бренд-акцентов.
- Заголовки Roboto Condensed Bold 700; дополнительный текст Inter; проверять кириллицу. Шрифт — реальный текстовый/векторный слой, не нарисованный генератором.
- При применимости одна фирменная цельная черта: зелёная для клуба, пыльно-розовая для группового фитнеса. Если физическая пиктограмма/предписывающий знак от этого хуже читается, зафиксировать мотивированное исключение. Нормативные знаки безопасности не перекрашивать ради бренда.
- Только утверждённые оригиналы логотипов из MASTER, проверить SHA-256 по реестру. Не реконструировать, не перерисовывать, не искажать. Слоган со стрелками — только утверждённый EPS.
- Настоящие люди, помещения, оборудование, карты, QR, интерьер и интерфейсы — только подтверждённые исходники; AI-концепт маркировать как концепт, не выдавать вымышленное помещение за существующее.

## Для физических носителей
Учитывать высоту монтажа, освещение, ракурс и дистанцию чтения. Пиктограммы: простой силуэт, устойчивые пропорции, минимум мелких деталей, общая графическая система серии. Проверять квадратный знак в фотографии конкретной стены в реальном масштабе. Для вывесок и печати фиксировать размеры в мм, материал, технологию, способ монтажа, требуемую версию исходника и проверку подрядчиком; нормы и конструктив не выдумывать.

## Критерий выдачи
Перед финалом проверить актуальность MASTER, правильность направления, композицию, контраст, читаемость на рабочей дистанции, русские буквы, отсутствие выдуманных объектов, верные размеры, подготовку векторного или растрового мастера, применимые QA из Visual System. Выпускать: редактируемый исходник + проверенное превью + техспецификацию/комплект экспорта + короткий QA-отчёт. Если чего-то нет — статус DRAFT/BLOCKED, назвать что не проверено. Нельзя утверждать READY до фактической проверки существующего файла.
