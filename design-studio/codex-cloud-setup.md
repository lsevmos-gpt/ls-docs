# Codex Cloud / другой проект

Если Codex запускается в GitHub-репозитории ls-docs, AGENTS.md и проектные skills/subagents уже находятся в корне репозитория. Проверить /skills и попросить использовать ls-design-studio.

Если Codex запущен в ДРУГОМ облачном репозитории, пользовательская установка на вашем Windows-компьютере не переносится туда. Вы можете дать Codex следующую задачу:

«Подключи в ТЕКУЩИЙ репозиторий систему Liniya Sporta Design Studio из открытого GitHub-репозитория lsevmos-gpt/ls-docs. Скопируй папки .agents/skills/ls-* и .codex/agents/ls_*.toml. Не перезаписывай существующие одноимённые файлы и не меняй деплой/сайт. Добавь в AGENTS.md текущего репозитория раздел, который применяется только к дизайнерским задачам бренда. Укажи получившиеся файлы и проверь, что /skills видит ls-design-studio. Не копируй приватные MASTER-логотипы без отдельного разрешения. При недоступности GitHub или прав на запись сообщи конкретное ограничение».

Если вам нужны skills во ВСЕХ локальных проектах — используйте install.ps1 (Windows) или install.sh (macOS/Linux), затем перезапустите Codex. Для ChatGPT веб-плагин создаётся отдельно через @Plugin Creator, если доступен вашей рабочей области.
