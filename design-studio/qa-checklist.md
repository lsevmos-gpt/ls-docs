# Production QA · дизайн физических носителей

Это ДОПОЛНЕНИЕ к обязательным P01–P18, F01–F08 и C01–C08 из действующей Visual System; не заменяет их.

| ID | Проверка | Критичность |
|---|---|---|
| S01 | Актуальный указатель Visual System и MASTER открыты, версия зафиксирована | BLOCKER |
| S02 | Выбрано направление клуб / групповой фитнес, палитры не смешаны | BLOCKER |
| S03 | Оригинальный логотип/слоган не искажён, проверен по MASTER | BLOCKER если присутствует |
| S04 | Основной знак/надпись считывается с реальной дистанции и ракурса | BLOCKER |
| S05 | Отсутствуют мелкие неконтрастные детали; силуэт ясен за 1–2 секунды | HIGH |
| S06 | Серия знаков унифицирована по сетке, массе, полям и стилю | HIGH |
| S07 | Проверен фотомонтаж в реальном месте установки с корректным размером | HIGH |
| S08 | Указаны физические размеры, ориентация, материал и крепление | HIGH для производства |
| S09 | Указаны редактируемый мастер, формат экспорта, версия и цветовое пространство | HIGH |
| S10 | Нет поддельных людей, помещений, оборудования, QR-кодов, цен, адресов | BLOCKER |
| S11 | Знаки безопасности и доступности не нарушают требования подрядчика / действующих норм | BLOCKER для регулируемых носителей |
| S12 | Поставщик подтвердил технологические параметры (вылеты, цветопробы, отверстия, контуры реза), если требуется | BLOCKER перед печатью |

Метод тестирования: полноразмерный просмотр (максимально близкий к реальному размеру), фото стены/фасада с макетом и указанной дистанцией, уменьшенный предпросмотр ряда пиктограмм, отдельное сравнение в монохроме и на слабом контрасте, проверка правильности кириллицы.

Если исходника фото/размера нет — можно показать концепцию, но не присваивать READY для монтажного/производственного файла. Логотип из GENERATIVE AI не является оригиналом. Заявление о печатной готовности требует конкретного файла, проверки экспорта и подтверждения производственных параметров.
