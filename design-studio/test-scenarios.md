# Приёмочные сценарии Liniya Sporta Design Studio

## Сценарий 1: квадратная табличка «Скалодром»
Дано: фото конкретной стены с рядом высоко расположенных квадратных табличек. Пользователь хочет собственную читаемую графическую систему, не фотореализм и не копирование прежнего макета.

Ожидаемая маршрутизация: ls-design-studio → ls-brand → ls-signage + ls-pictograms → ls-design-critic. Вызвать typography только если будет текст, print — перед производством.

Ожидаемые действия:
- прочитать актуальный бренд-указатель и исходные размеры; не выдумывать высоту;
- создать максимум три разные по логике силуэта композиции;
- показать скалолаза на стене, зацепы и характерное положение тела, без анатомических мелочей;
- сравнить с табличкой запрета обуви в едином ряду; проверить оптическую массу и визуальную дистанцию;
- выполнить мокап на оригинальной фотографии стены и тест малого размера;
- выпускать мастер SVG/PDF после проверки, не только AI-картинку;
- без вымышленного логотипа и несуществующих элементов помещения.

Провал: случайный человек в динамической позе не считывается как скалолазание, обилие тонких деталей, неправильная перспектива монтажа, генерация логотипа.

## Сценарий 2: новая интерьерная вывеска у ресепшена
Ожидаемая маршрутизация: director → interior + typography + signage → critic → print (при производстве). Проверить реальный фотоматериал, освещение, габариты, материалы, крепление; при недостатке чертежей маркировать концепт.

Провал: помещение самовольно перестроено на визуализации, выдуманы материалы, забыта высота чтения и монтаж.

## Сценарий 3: фасадный баннер 7000 × 3000 мм
Ожидаемая маршрутизация: director → brand + typography + print → critic. Проверить фактический исходник, физическое соотношение 7:3, масштаб, потребность в upscale, рабочую дистанцию, типографику и требования типографии.

Провал: механическое требование 300 ppi для 7 метров без учёта дистанции и подрядчика, поддельные лица, неоригинальный логотип, обещание READY без экспортированного файла.

## Сценарий 4: групповое фитнес-направление
Ожидаемая маршрутизация: director → brand + typography → critic. Все групповые занятия, включая силовые, строго в тёплой палитре Visual System; не ставить зелёную клубную черту или общий клубный логотип.

Провал: ярко-зелёная палитра в направлении группового фитнеса.
